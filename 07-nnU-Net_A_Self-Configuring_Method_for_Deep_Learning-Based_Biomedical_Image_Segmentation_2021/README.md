## Translation Scope

本文档依据用户提供的 `07--nnU-Net.pdf`，仅翻译论文正文，包含摘要、开篇引言、结果、讨论，以及 PDF 第 10–11 页独立排版的 Methods（方法）部分。方法部分属于论文正文，未按附录排除。

翻译保留原文的章节顺序、标题层级、列表、数学符号与公式。为便于 Markdown 阅读，将原文未单独标题的摘要与开篇部分分别标为“摘要”和“引言”；将段首的小节标题整理为对应层级标题。公式保持原有数学内容与行内呈现方式，不添加推导或解释。专业术语首次出现时按需保留英文或缩写。

未包含：

- 正文中的作者信息、作者单位、邮箱、论文编号、DOI、项目 GitHub 链接及资助信息。
- 图片、图注、图片内文字和表格内容；Figure 1–6 保留省略位置标记，Figure 2 内的参数表随该图省略。
- 文献引用编号与参考文献列表。
- 致谢、作者贡献、利益冲突、出版信息及研究报告清单（Reporting Summary）。
- 附录、补充材料，以及正文之外的数据可用性和代码可用性声明。
- 额外的公式解释、推导或研究笔记。

正文保留理解内容所需的图号和补充说明交叉引用，但不补译相应图注或补充材料。所有实验结果、排行榜信息、软件版本和技术设置均对应所提供论文的历史版本。
