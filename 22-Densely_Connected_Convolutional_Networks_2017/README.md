## Translation Scope

译文涵盖摘要及第 1 至 6 节，包括引言、相关工作、DenseNet 网络结构、实验、讨论和结论。保留正文中的数学公式、原编号、实验数值和图表交叉引用。5 幅图和 3 张表均在相关段落留有位置标记。

正文略去作者资料、文献引用编号、图表内容与题注、代码仓库链接、致谢、资助信息及参考文献。数学公式按原文排写，未另加推导。
